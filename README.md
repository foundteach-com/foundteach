# FoundTeach

Sitio web institucional de **FoundTeach** — empresa de ingeniería de software.

## Desarrollo local

```bash
npm install
npm start
```

El sitio estará disponible en `http://localhost:3000`.

## Despliegue

El proyecto está configurado para desplegarse en [Railway](https://railway.app). La conexión con GitHub realiza el deploy automático en cada push.

## Estructura

```
foundteach/
├── index.html      # Página principal
├── css/
│   └── styles.css  # Estilos
├── js/
│   └── main.js     # Scripts
└── package.json    # Dependencias Node
```
